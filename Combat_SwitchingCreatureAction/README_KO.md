# 행동 전환 + 범위 사격 플러그인 (타이푼 연동판)

데몬(daemon1995)의 `Combat_SwitchingCreatureAction` 최신판(2026-11-10)을 가져와서 이 포크에서 세 가지를 바꿨습니다.

1. 범위 사격 종류를 **타이푼 에디터(MCrEdit) 설정**에서 읽습니다.
2. 기본 부대 목록(45·64·65·94·95·196)을 지웠습니다. 싸이클롭스 번호(94·95)가 자동으로 범위 사격 부대가 되던 문제가 없어집니다.
3. 안내 문구를 한국어로 바꿨습니다(`Lang\combat_switching_actions.json`).

원래 설명서(러시아어)는 `README.md`에 그대로 있습니다.

## 설치

GitHub Actions의 `area_shot` 결과물을 풀면 아래 폴더가 나옵니다. 모드 폴더(예: `Mods\New Upgrade Mod\`) 안의 같은 이름 폴더에 그대로 넣으세요.

```
EraPlugins\Combat_SwitchingCreatureAction.era
Data\icm001q.def ~ icm012q.def, icmaltq.def   (버튼 그림 9개)
Lang\combat_switching_actions.json            (한국어 문구 + 예외 설정)
```

## 조작

| 키 | 하는 일 |
|---|---|
| ALT 또는 하단 바의 행동 전환 버튼 | 이 부대가 할 수 있는 행동을 차례로 바꿈(근접 → 사격 → … → 범위 사격) |
| G | 범위 사격 목표 선택 창을 바로 엶(범위 사격 부대 차례에만) |
| 목표 선택 중 왼쪽 클릭 | 그 칸에 사격(빈 칸, 아군 칸도 가능) |
| 목표 선택 중 ESC / 오른쪽 클릭 | 취소, 턴 소모 없음 |

AI도 빈 칸을 포함한 모든 칸을 게임 자체 평가로 따져서 가장 좋은 칸에 쏩니다.

## 어떤 부대가 범위 사격을 하나

1. **켜기/끄기:** 타이푼의 `Advanced shooting` **체크박스**(게임의 범위 사격 플래그)와 `Shooting army`가 켜져 있고, 지금 쏠 수 있어야 합니다.
2. **종류:** 타이푼의 `Advanced shooting` **드롭다운**을 따릅니다.
   - `Fireball` → 화염: 둘레의 화염 면역 부대는 피해 없음
   - `Death cloud` → 죽음의 구름: 둘레의 살아 있지 않은 부대는 피해 없음
   - `None` → 이 기능 없음
   - 가운데의 직접 목표는 종류와 상관없이 정상 피해를 받습니다.
3. **예외(선택):** `Lang\combat_switching_actions.json`의 `area_shot_types`에 부대 번호를 적으면 타이푼보다 우선합니다.
   - 값: `0` 끔, `1` 화염, `2` 죽음의 구름, `3` 물리(둘레 모든 부대 피해, 타이푼에 없는 종류)
   - 1~3을 적은 사격 부대는 타이푼 체크박스와 상관없이 범위 사격 플래그가 켜집니다.

   ```json
   "area_shot_types": {
     "95": 3,
     "45": 0
   }
   ```

4. 타이푼 파일을 못 찾으면 원래 게임대로 45번 화염, 64·65번 죽음의 구름만 씁니다.

타이푼 파일은 게임 폴더 기준 `EraPlugins\MCrEdit\MonstersSetup.mop`에서 찾습니다. ERA가 모드 폴더를 게임 폴더에 겹쳐 보여 주기 때문에, 모드 이름이나 게임 폴더 이름(`(26.11.08)` 같은 부분)이 바뀌어도 그대로 찾습니다. 파일 모양이 예상과 다르면(크기 254000바이트가 아니거나 드롭다운 값이 0~2가 아니면) 읽지 않고 4번으로 넘어갑니다.

## 확인과 ERM

```erm
!!IF:M^타이푼 파일: %s(aimedShotTyphonFile)^;    비어 있으면 타이푼 파일을 못 찾은 것
!!IF:M^95번 종류: %i(js_aimedShotType_95)^;      0 없음, 1 화염, 2 죽음의 구름, 3 물리
!!SN:W^js_aimedShotType_95^/3;                    게임 중에 종류 바꾸기(다음 사격부터)
```

종류 값은 맵을 시작하거나 불러올 때마다 다시 정해집니다.
