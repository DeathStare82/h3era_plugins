# 행동 전환 + 범위 사격 플러그인 (타이푼 연동판)

데몬(daemon1995)의 `Combat_SwitchingCreatureAction` 최신판(2026-11-10)을 가져와서 이 포크에서 바꾼 것입니다.

1. 범위 사격 종류를 **타이푼 에디터(MCrEdit) 설정**에서 읽습니다.
2. 기본 부대 목록(45·64·65·94·95·196)을 지웠습니다. 싸이클롭스 번호(94·95)가 자동으로 범위 사격 부대가 되던 문제가 없어집니다.
3. 안내 문구를 한국어로 바꿨습니다(`Lang\combat_switching_actions.json`).
4. **사격 모드에서도 빈 칸으로 이동**할 수 있습니다. 전에는 근접 → 사격으로 바꾸거나 범위 사격 창을 닫은 뒤에는 그 부대가 이동할 수 없었습니다.
5. 행동 전환 버튼(`Data\icmaltq.def`)을 히어로즈 2(석세션 워) 스타일로 새로 그렸습니다. 46×36 크기, 24장(8가지 행동 × 보통/누름/비활성)이고, **범위 사격은 일반 사격과 다른 그림**(활 + 폭발)입니다.
6. 버튼 폭이 DEF 그림 폭을 따라갑니다(최대 46px). 옮겨진 기존 버튼들도 46px 폭으로 그려지고 눌립니다.
7. 겨냥 창에서 **ERM으로 하단바 힌트를 바꿀 수 있습니다**(`!?FU(OnAreaShotHint)`, 아래 참고).

원래 설명서(러시아어)는 `README.md`에 그대로 있습니다.

## 설치

GitHub Actions의 `area_shot` 결과물을 풀면 아래 폴더가 나옵니다. 모드 폴더(예: `Mods\New Upgrade Mod\`) 안의 같은 이름 폴더에 그대로 넣으세요.

```
EraPlugins\Combat_SwitchingCreatureAction.era
Data\icmaltq.def                              (H2 스타일 행동 전환 버튼)
Lang\combat_switching_actions.json            (한국어 문구 + 예외 설정)
```

### 하단 바의 기존 버튼(q 파일)

이 플러그인은 하단 바에 행동 전환 버튼 한 칸을 끼워 넣으려고 기존 버튼들을 모두 47px 간격으로 다시 배치하고, 그림을 `q`가 붙은 파일 이름에서 읽습니다. 원래 H3 버튼(48px)은 이 간격에 들어가지 않아서 데몬이 44px짜리 `q` 그림을 따로 만들었습니다.

H2 버튼(46px)은 그대로 들어가므로, 모드의 기존 H2 버튼을 **복사해서 이름에 q만 붙이면** 됩니다.

| 기존 파일 | 복사본 이름 | 버튼 |
|---|---|---|
| icm003.def | icm003q.def | 설정 |
| icm001.def | icm001q.def | 항복 |
| icm002.def | icm002q.def | 도망 |
| icm004.def | icm004q.def | 자동 전투 |
| icm005.def | icm005q.def | 마법 |
| icm006.def | icm006q.def | 대기 |
| icm007.def | icm007q.def | 방어 |
| icm012.def | icm012q.def | 전술 단계의 '전투 시작'(폭 188px 이하) |

- 폭은 46px 이하여야 옆 버튼을 덮지 않습니다.
- q 파일이 하나라도 없으면 전투를 열 때 파일을 찾지 못해 오류가 날 수 있으니 8개 모두 만들어 두세요.
- 결과물에는 q 파일을 넣지 않았습니다. 데몬의 H3 스타일 원본은 저장소 `Data` 폴더에 참고용으로 남아 있습니다.

## 조작

| 키 | 하는 일 |
|---|---|
| ALT 또는 하단 바의 행동 전환 버튼 | 이 부대가 할 수 있는 행동을 차례로 바꿈(근접 → 사격 → … → 범위 사격) |
| G | 범위 사격 목표 선택 창을 바로 엶(범위 사격 부대 차례에만) |
| 목표 선택 중 왼쪽 클릭 | 그 칸에 사격(빈 칸, 아군 칸도 가능) |
| 목표 선택 중 ESC / 오른쪽 클릭 | 취소, 턴 소모 없음 |

AI도 빈 칸을 포함한 모든 칸을 게임 자체 평가로 따져서 가장 좋은 칸에 쏩니다.

## 어떤 부대가 범위 사격을 하나

1. **켜기/끄기:** 타이푼의 `Advanced shooting` **체크박스**(게임의 범위 사격 플래그)와 `Shooting army`가 켜져 있고, 지금 쏠 수 있어야 합니다.
2. **종류:** 타이푼의 `Advanced shooting` **드롭다운**을 따릅니다.
   - `Fireball` → 화염: 둘레의 화염 면역 부대는 피해 없음
   - `Death cloud` → 죽음의 구름: 둘레의 살아 있지 않은 부대는 피해 없음
   - `None` → 이 기능 없음
   - 가운데의 직접 목표는 종류와 상관없이 정상 피해를 받습니다.
3. **예외(선택):** `Lang\combat_switching_actions.json`의 `area_shot_types`에 부대 번호를 적으면 타이푼보다 우선합니다.
   - 값: `0` 끔, `1` 화염, `2` 죽음의 구름, `3` 물리(둘레 모든 부대 피해, 타이푼에 없는 종류)
   - 1~3을 적은 사격 부대는 타이푼 체크박스와 상관없이 범위 사격 플래그가 켜집니다.

   ```json
   "area_shot_types": {
     "95": 3,
     "45": 0
   }
   ```

4. 타이푼 파일을 못 찾으면 원래 게임대로 45번 화염, 64·65번 죽음의 구름만 씁니다.

타이푼 파일은 게임 폴더 기준 `EraPlugins\MCrEdit\MonstersSetup.mop`에서 찾습니다. ERA가 모드 폴더를 게임 폴더에 겹쳐 보여 주기 때문에, 모드 이름이나 게임 폴더 이름(`(26.11.08)` 같은 부분)이 바뀌어도 그대로 찾습니다. 파일 모양이 예상과 다르면(크기 254000바이트가 아니거나 드롭다운 값이 0~2가 아니면) 읽지 않고 4번으로 넘어갑니다.

## 확인과 ERM

```erm
!!IF:M^타이푼 파일: %s(aimedShotTyphonFile)^;    비어 있으면 타이푼 파일을 못 찾은 것
!!IF:M^95번 종류: %i(js_aimedShotType_95)^;      0 없음, 1 화염, 2 죽음의 구름, 3 물리
!!SN:W^js_aimedShotType_95^/3;                    게임 중에 종류 바꾸기(다음 사격부터)
```

종류 값은 맵을 시작하거나 불러올 때마다 다시 정해집니다.

## 겨냥 창의 하단바 힌트 (ERM)

겨냥 창이 열려 있는 동안에는 전투의 `OnBattleMouseHint`(MM0)가 돌지 않습니다. 대신 마우스가 다른 칸으로 옮겨갈 때마다 `!?FU(OnAreaShotHint)`가 불립니다.

플러그인은 이 함수를 ERA가 함수 이름과 같은 이름의 변수에 넣어 두는 함수 번호로 찾아 `FU번호:P...`로 부릅니다. 그래서 `AllocErmFunc`가 없는 옛 ERA(3.9.11 이하)에서도 됩니다(ERA 3.7 이상).

| 변수 | 뜻 |
|---|---|
| x1 | 쏘는 부대(0~41) |
| x2 | 마우스 헥스(전장 밖이면 -1) |
| x3 | 그 칸의 부대, 빈 칸이면 -1 |
| x4 | 쏠 수 있는 칸이면 1 |
| x5 | 종류: 1 화염, 2 죽음의 구름, 3 물리 |
| x6 | 쏘는 부대와의 거리 |
| x7 | 꺾인 화살(피해 절반)이면 1 |

문구를 `!!SN:W^aimedShotHint^/z-1;`처럼 넣으면 플러그인 기본 문구 대신 그 문구가 나옵니다. 아무것도 넣지 않으면 기본 문구가 나옵니다. 겨냥 창에서는 `!!MM:M` 대신 이 변수를 쓰세요.

- 부대가 있는 칸에서는 게임 옵션과 상관없이 항상 피해 예상 계산을 합니다. 그래서 `OnStackToStackDamage`가 이 칸의 목표로 불립니다(x7=1 사격, x9=1 예상 계산).
- 변수는 칸이 바뀔 때마다, 피해 예상 계산보다 먼저 비워집니다. 그래서 `OnStackToStackDamage`에서 넣어도 그대로 나옵니다.
- `area_shot_hint.erm`
  - `OnAreaShotHint`: 빈 칸·아군 칸은 예전 범위 사격 MM0 코드의 "마우스 안내", 적군 칸은 아래 함수의 문구를 씁니다.
  - `StackDamageHint_Build`: 평소 MM0 적군 힌트 코드를 함수로 옮긴 것입니다(x1 = 헥스, 문구를 만들면 x2 = 1, 문구는 `SN:W^StackDamageHint^`).
  - 모드의 `Data\s` 폴더에 넣거나 기존 스크립트에 붙여 넣으세요(둘 중 하나만).
