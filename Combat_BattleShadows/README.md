# Combat_BattleShadows — 전투 헥스 그림자 (v10)

ERM에서 전장의 원하는 헥스에 **파이어볼 조준 때와 똑같은 그림자**를 깔고, 그 칸의 부대에 깜빡이는 하늘색 테두리를
켜는 ERA 플러그인입니다. 화면 표시만 바꾸므로 네트워크 전투에서도 동기화 문제가 없습니다.

설치 파일은 `Combat_BattleShadows.era` 하나입니다. 모드의 `eraplugins` 폴더에 넣습니다.

## v10에서 바뀐 것: 이동 범위를 다시 계산해 바로 표시

- `BattleShadow_HideMovement`의 `P0`이 이동 범위를 부대의 **현재 속도로 다시 계산**한 뒤 바로 다시 그립니다.
  화면 갱신 코드를 따로 넣을 필요가 없습니다. 주문 모드를 끝낼 때는 **속도를 먼저 되돌리고** `P0`을 부릅니다.
- `BattleShadow_RefreshMovement`(새 함수): ERM으로 속도를 바꾼 뒤 이동 범위를 다시 계산해 바로 보여 줍니다.
  범위를 숨긴 상태에서는 계산만 해 두고, `P0` 때 보입니다.

```erm
!!BM(부대):S(원래 속도);                     [속도를 먼저 되돌림]
!!FU(BattleShadow_HideMovement):P0;         [다시 계산해서 바로 표시]

!!FU(BattleShadow_RefreshMovement):P;       [숨기지 않은 채 속도만 바꿨을 때]
```

## v9에서 더해진 것: 칸 제외 (`BattleShadow_SkipHexes`)

지정한 **칸**을 모든 그림자에서 뺍니다(커서 칸 포함). 가운데가 비는 얼음고리 같은 범위에 씁니다.
`SkipStacks`는 부대를 빼고, `SkipHexes`는 칸을 뺍니다.

```erm
!?MM0;
!!MM:D?y9;                                  [마우스가 있는 칸]
!!FU(BattleShadow_Radius):Py9/1/1;          [반경 1, 테두리 켬]
!!FU(BattleShadow_SkipHexes):Py9;           [가운데 칸 제외 = 얼음고리]
```

가운데에 선 1칸 부대는 테두리도 켜지지 않습니다. 2칸 부대는 다른 한 칸이 고리 안에 있으면 테두리가 켜집니다.

## v8에서 더해진 것: 이동 범위 음영 숨기기

`BattleShadow_HideMovement`로 부대의 이동 가능 범위 음영을 껐다 켤 수 있습니다. 원본 파이어볼 조준 때처럼 범위
그림자만 보이게 할 때 씁니다. 화면만 바뀌고, 게임 설정의 "이동 범위 그림자" 값과 부대의 실제 이동은 그대로입니다.

## v7에서 바뀐 점: 게임의 그림자 함수로 그립니다

v6까지는 화면 그림 위에 플러그인이 직접 색을 어둡게 칠했습니다(비슷하지만 같지는 않음). v7은 **게임이 커서 그림자와
파이어볼 범위를 그릴 때 쓰는 바로 그 함수**(`0x493A20`, 범위 사격 플러그인이 쓰는 것과 같은 함수)로 그립니다.
그래서 색, 모양, 부대가 그림자 위에 그려지는 방식이 파이어볼과 똑같습니다.

- 게임은 마우스가 칸을 옮길 때 그 칸 하나에 커서 그림자를 칠하고, 그다음 힌트(MM0)를 만듭니다. v7은 그 칸 요청을
  잠깐 맡아 두었다가, MM0에서 ERM이 준 모양과 **합쳐서 한 번에** 그립니다. 칸을 옮길 때마다 한 번만 그려지므로
  깜빡임이 없습니다.
- 커서가 있는 칸은 게임이 원래 칠하던 대로 항상 포함됩니다(단, `SkipStacks`로 뺀 부대 칸은 제외).
- 게임의 그림자 함수는 한 번에 **19칸**까지만 저장해 둘 수 있습니다(인페르노 크기). 19칸까지는 게임 함수를 그대로
  부릅니다. 그보다 크면(반경 3 = 37칸, 반경 4 = 61칸, 여러 모양을 합쳐 20칸 이상) 같은 그리기 함수들을 플러그인의
  187칸짜리 저장 공간으로 돌리고, 파이어볼 조준이 칸마다 하는 것처럼 전장을 한 번 다시 그립니다. 모양은 같습니다.
  다시 19칸 이하가 되면 바로 게임 함수로 돌아갑니다.
- 게임 설정의 **커서 그림자**가 꺼져 있으면 파이어볼처럼 그림자는 나오지 않고 테두리만 나옵니다
  (범위 사격 그림자와 같은 조건).
- 파이어볼 조준, 범위 사격 조준, 전투 행동 시작처럼 게임이 그림자를 직접 쓰는 순간에는 게임에 넘겨줍니다. 그때
  ERM 모양은 지워지고, 다음 MM0가 새로 줍니다.

## ERM 함수

ERA는 `!!FU(이름):P`를 같은 이름으로 등록된 플러그인에도 전달합니다. 아래 함수들은 ERM 쪽에서 `!?FU(...)`를
따로 만들지 않고 바로 호출합니다. 헥스 번호는 `줄 × 17 + 칸`이고, 0칸·16칸(영웅 자리)은 무시합니다. 그래서
생략한 값(0)도 무시됩니다. v6과 함수와 인자가 같으므로 ERM은 고칠 필요가 없습니다.

| 함수 | 인자 | 하는 일 |
|---|---|---|
| `BattleShadow_Follow` | 반경(0~4, -1 끔) / 테두리(1) | 마우스가 있는 칸 둘레를 플러그인이 직접 따라가며 칠함 |
| `BattleShadow_Radius` | 헥스 / 반경(0~4) / 테두리 | 지정한 칸 둘레를 칠함 |
| `BattleShadow_Hexes` | 헥스 x1~x10 / 테두리(x11) | 적은 칸만 칠함. -1은 빈자리 |
| `BattleShadow_Stacks` | 헥스 x1~x10 / 테두리(x11) | 그 칸에 서 있는 **부대 전체**(2칸 부대는 두 칸 모두)를 칠함. 연쇄 마법용 |
| `BattleShadow_SkipStacks` | 헥스 x1~x16 | 그 칸에 서 있는 부대는 어떤 그림자·테두리에서도 **빠짐**(커서 칸 포함). 마법이 안 통하는 부대용 |
| `BattleShadow_SkipHexes` | 헥스 x1~x16 | 그 **칸**은 어떤 그림자에서도 빠짐(커서 칸 포함). 얼음고리의 가운데처럼 구멍 난 범위용 |
| `BattleShadow_Clear` | 없음 | 그림자를 모두 지움 (따라가기 포함, 이동 범위 숨기기는 그대로) |
| `BattleShadow_HideMovement` | 숨김(1 숨김 / 0 보임) / 자동복구(1) | 이동 범위 음영을 숨기거나 다시 보임. 자동복구 1이면 다음 전투 행동이 시작될 때 저절로 다시 보임 |
| `BattleShadow_RefreshMovement` | 없음 | 이동 범위를 현재 속도로 다시 계산해 바로 보여 줌 (숨긴 상태면 계산만) |
| `BattleShadow_Debug` | 결과 13개 | 진단용 (아래 참고) |

반경별 칸 수: 0 = 그 칸만, 1 = 7칸(파이어볼), 2 = 19칸(인페르노), 3 = 37칸, 4 = 61칸.

### 이동 범위 숨기기

```erm
!!FU(BattleShadow_HideMovement):P1;     [이동 범위 숨김: 다시 켤 때까지, 턴이 넘어가도 유지]
!!FU(BattleShadow_HideMovement):P0;     [다시 보임]
!!FU(BattleShadow_HideMovement):P1/1;   [숨김, 다음 전투 행동(시전 등)이 시작되면 저절로 다시 보임]
```

- 같은 값으로 다시 불러도 아무 일도 하지 않으므로 MM0 안에서 매번 불러도 됩니다. 실제로 바뀔 때만 전장 배경을
  한 번 다시 만들어 바로 보여 줍니다(게임이 설정을 바꿀 때와 같은 방법).
- `P0`은 이동 범위를 부대의 현재 속도로 다시 계산해서 보여 줍니다. 속도를 바꿨다면 속도를 먼저 되돌린 뒤
  `P0`을 부릅니다. 숨기지 않은 채 속도만 바꿨다면 `BattleShadow_RefreshMovement`를 부릅니다.
- 전투가 시작되거나 끝나면 항상 "보임"으로 돌아갑니다.
- 그림자(`Follow`, `Radius` 등)와는 따로 동작합니다. `BattleShadow_Clear`로는 다시 켜지지 않습니다.
- 전술 단계의 배치 구역 표시는 숨기지 않습니다.

## 언제 지워지나

| 때 | 지워지는 것 |
|---|---|
| MM0 트리거가 다시 시작될 때 | `Radius`, `Hexes`, `Stacks`, `SkipStacks`, `SkipHexes` (따라가기는 유지) |
| 커서가 MM0 없이 다른 칸으로 갈 때 | `Radius`, `Hexes`, `Stacks` |
| 게임이 그림자를 직접 쓸 때(마법·범위 사격 조준 등) | `Radius`, `Hexes`, `Stacks`, `SkipStacks`, `SkipHexes` |
| 전투 행동 시작, 전투 시작/끝, 게임 종료/불러오기 | 전부 (따라가기·테두리 포함) |

이동 범위 숨기기는 위 표와 상관없이 `P0`으로 다시 켤 때까지 유지됩니다. 예외는 자동복구(`P1/1`)일 때의 다음
전투 행동, 그리고 전투 시작/끝입니다.

같은 MM0 안에서 여러 함수를 부르면 모양이 합쳐지고, 화면은 그 마우스 이동 처리가 끝날 때 한 번만 바뀝니다.

## 사용 예

### 범위 지속 마법 (버서크 같은 것)

```erm
!?MM0;
!!FU(BattleShadow_Follow):P-1;                  [일단 끔]
!!SN:W^Ready_to_Cast_spell_by_Mod^/?y7;
!!FU&y7=0:E;                                    [주문 준비 중이 아니면 끝]
!!FU(BattleShadow_Follow):Pv495/1;              [반경 v495로 마우스를 따라감, 테두리 켬]
!!re i/0/41;                                    [모든 부대를 보며]
  !!BMi:N?y30;
  !!co&y30<=0;                                  [없는 부대는 건너뜀]
  ; 여기서 이 마법이 부대 i에게 안 통하면 y31=1 (아군에게 저주, 면역 등 모드 규칙대로)
  !!BMi:P?y32;                                  [부대 위치 헥스]
  !!FU(BattleShadow_SkipStacks)&y31=1:Py32;     [안 통하는 부대는 그림자에서 뺌]
!!en;
```

### 연쇄 마법 (두 부대에 연속으로)

```erm
!?MM0;
; y1 = 첫 번째 대상 부대 위치, y2 = 두 번째 대상 부대 위치 (모드 규칙대로 계산, 없으면 -1)
!!FU(BattleShadow_Stacks):Py1/y2/-1/-1/-1/-1/-1/-1/-1/-1/1;
```

## 진단: `BattleShadow_Debug`

MM0 트리거 맨 끝에 아래 두 줄을 넣으면 전투 화면 아래 힌트 줄에 상태가 표시됩니다.

```erm
!!FU(BattleShadow_Debug):P?y20/?y21/?y22/?y23/?y24/?y25/?y26/?y27/?y28/?y29/?y30/?y31/?y32;
!!MM:M^v%y20 shown=%y21 hint=%y22 follow=%y23 skip=%y24 game=%y25 own=%y26 full=%y27 cursor=%y28 opt=%y29 hook=%y30 move=%y31 xhex=%y32^;
```

| 표시 | 뜻 |
|---|---|
| `v` | 플러그인 버전(지금 10). 0이면 플러그인이 호출되지 않은 것 |
| `shown` | 지금 그림자 층에 칠해진 헥스 수 |
| `hint` | 이번 MM0에서 `Radius`·`Hexes`·`Stacks`로 요청한 헥스 수 |
| `follow` | 따라가기 반경. -1이면 꺼짐 |
| `skip` | `SkipStacks`로 받은 헥스 수 |
| `game` | 게임 그림자 함수로 그린 횟수 (19칸 이하) |
| `own` | 플러그인 저장 공간으로 그린 횟수 (20칸 이상) |
| `full` | 전장 전체를 다시 그린 횟수 (20칸 이상, 테두리 변경, 이동 범위 켜기/끄기) |
| `cursor` | 플러그인이 보는 커서 헥스 |
| `opt` | 게임의 커서 그림자 설정. 0이면 그림자가 안 나옴(파이어볼과 같음) |
| `hook` | 1이면 마우스 이동 연결 정상(칸마다 한 번 그림). 0이면 다른 모드가 같은 자리를 먼저 고친 것: 그림자는 나오지만 칸을 옮길 때 한 번 더 그림 |
| `move` | 1이면 `HideMovement`로 이동 범위를 숨기는 중 |
| `xhex` | `SkipHexes`로 받은 칸 수 |

## 개발자용 메모

- 주소는 게임 실행 파일의 기계어를 직접 읽어 확인했습니다.
  - `0x493A20(combat, anchorHex, H3Vector<INT32>*, BOOL8 force)`: 이전 목록을 저장 버퍼(`combat+0x53B4`, 855×52
    = 45픽셀 19칸, 칸 번호는 `square+0x4D`)에서 배경판(`combat->drawBuffer`)에 되돌리고, 새 칸의 배경을 저장한 뒤
    `CCellShd.pcx`로 어둡게 칠합니다(`0x44E370`). 그다음 이전·새 칸을 감싸는 사각형만 다시 그려 화면에 보냅니다.
    커서 그림자 설정이 꺼졌거나, 숨은 전투이거나, `anchorHex`가 지난번(`0x6772D8`)과 같고 force가 0이면 바로
    돌아갑니다. 그린 목록은 `0x696A08`(H3API `H3BattleShadowHexes`)에 남습니다.
  - `0x493F10(combat, hex, flag)`: 커서 칸 하나짜리 그림자. 전투 화면 처리 함수(`0x4746B0`)의 마우스 이동 부분이
    `0x474D0F`에서 부르고, 그 뒤에 힌트 함수(`0x4923C0`, WoG가 `0x492E4F`에서 MM0를 부름)가 실행됩니다.
  - 파이어볼류 조준(`0x59FBB0`)은 범위를 `0x493A20`(force 1)으로 칠한 뒤 `0x493FC0(1,1,0,0,1,0)`으로 전장을 다시
    그립니다. 전투 행동 시작(`0x4786B0`)은 `0x493F10(-1, 1)`로 그림자를 지웁니다.
- 플러그인이 거는 곳: `0x474D0F`(CALL 훅: 커서 요청을 맡아 둠, 그 자리가 원래의 `call 0x493F10`일 때만),
  `0x493A20`(SPLICE: 다른 사용자가 부를 때 ERM 모양을 지우고, 층에 플러그인 모양이 있으면 force로 다시 그림),
  `0x4746B0`(메시지 처리 끝에서 한 번에 그림).
- 20칸 이상은 `0x493A20`의 1~3단계(되돌리기, 배경 저장, `0x44E370` 칠하기)를 같은 함수(`0x44DF80` 복사)로
  187칸 저장 버퍼(게임과 같은 `0x44DC40` 생성자로 만듦, 칸 번호 = 헥스 번호)에서 하고, 화면은 `0x493FC0`으로
  다시 그립니다. 두 저장 버퍼는 동시에 쓰지 않습니다(게임 목록을 넘겨받을 때는 게임 버퍼의 칸에서 되돌림).
- 테두리는 `0x43ED00`으로 켜고, 실제로 바뀌면 `0x493FC0`으로 전장을 한 번 다시 그립니다. 게임이 이미 켜 둔
  테두리는 우리 것으로 치지 않습니다.
- 이동 범위 음영은 `0x4934B0(combat, full, recompute)`가 배경판에 그립니다. 이 함수는 원하는 범위(`+0x107`)를
  계산한 뒤 "이동 범위 그림자" 설정(`0x698814`)이나 전술 단계(`+0x13D68`)일 때만 칠합니다. 숨기는 동안
  플러그인은 이 함수(SPLICE)가 실행되는 동안에만 설정값을 0으로 읽게 하고 바로 되돌립니다. 범위 계산은 그대로
  일어나므로, 다시 보이게 하면 그 시점의 범위가 그려집니다. 켜고 끌 때는 그림자 층을 소리 없이 걷어 낸 뒤
  `doNotDrawShade = FALSE`로 배경을 다시 만들고(`0x4798F0`과 같은 방법), 그 위에 그림자를 다시 그립니다.
- 배경을 다시 만드는 `0x493870`은 `0x4934B0(1, 0)`(다시 계산 없음)을 부르므로 마지막으로 계산된 범위가
  그려집니다. 그래서 다시 보일 때(`P0`)와 `RefreshMovement`는 먼저 `0x4934B0(0, 1)`로 현재 부대의 범위를 다시
  계산합니다(`0x493350`, 부대의 현재 속도 사용).
- 배경 재생성이 예약된 상태(`doNotDrawShade == FALSE`)에서는 먼저 배경을 다시 만든 다음 그림자를 그립니다.
  그렇지 않으면 다음 다시 그리기의 재생성이 방금 그린 그림자를 지웁니다. 전장 위에 다른 창(마법책 등)이 있으면
  그 창이 닫힐 때까지 미룹니다.
