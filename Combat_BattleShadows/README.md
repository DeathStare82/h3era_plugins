# Combat_BattleShadows — 전투 헥스 그림자

ERM에서 전장의 원하는 헥스에 파이어볼 조준 때와 같은 그림자를 깔고, 그 칸에 있는 부대에 깜빡이는 하늘색
테두리를 켜는 ERA 플러그인입니다. 화면 표시만 바꾸므로 네트워크 전투에서도 동기화 문제가 없습니다.

설치 파일은 `Combat_BattleShadows.era` 하나입니다. 게임의 `Mods\WoG\eraplugins\` 폴더에 넣으면 됩니다.

## ERM 함수

ERA는 `!!FU(이름):P`를 같은 이름으로 등록된 플러그인에도 전달합니다. 그래서 아래 함수들은 ERM 쪽에서
`!?FU(...)`를 따로 만들지 않고 바로 호출합니다.

### 반경형: `BattleShadow_Radius`

```erm
!!FU(BattleShadow_Radius):P(헥스)/(반경)/(테두리);
```

| 값 | 뜻 |
|---|---|
| x1 헥스 | 중심 헥스. 보통 `!!MM:D`로 얻은 마우스 위치. -1이면 아무것도 안 함 |
| x2 반경 | 0~4. 0은 그 칸만, 1은 파이어볼(7칸), 2는 인페르노(19칸), 3은 37칸, 4는 61칸 |
| x3 테두리 | 1이면 범위 안 부대에 하늘색 테두리. 생략하면 0(테두리 없음) |

### 자유형: `BattleShadow_Hexes`

```erm
!!FU(BattleShadow_Hexes):P(칸1)/(칸2)/(칸3)/(칸4)/(칸5)/(칸6)/(칸7)/(칸8)/(칸9)/(칸10)/(테두리);
```

| 값 | 뜻 |
|---|---|
| x1~x10 | 그림자를 깔 헥스. -1이면 그 자리는 비움 |
| x11 테두리 | 1이면 그 칸들 위의 부대에 하늘색 테두리 |

뒤쪽 칸을 안 쓸 때는 그냥 생략해도 됩니다. 단, 테두리를 켜려면 11번째 자리까지 채워야 하므로 빈 자리를
-1로 채웁니다.

```erm
!!FU(BattleShadow_Hexes):P52/53/54;                         [3칸, 테두리 없음]
!!FU(BattleShadow_Hexes):P52/53/54/-1/-1/-1/-1/-1/-1/-1/1;  [3칸, 테두리 있음]
```

### 지우기: `BattleShadow_Clear`

```erm
!!FU(BattleShadow_Clear):P;
```

### 진단: `BattleShadow_Debug`

그림자가 안 보일 때 원인을 찾는 함수입니다. MM0 트리거 맨 끝에 아래 두 줄을 넣으면 전투 화면 아래 힌트 줄에
플러그인 상태가 표시됩니다.

```erm
!!FU(BattleShadow_Debug):P?y20/?y21/?y22/?y23/?y24/?y25/?y26/?y27/?y28;
!!MM:M^v%y20 mine=%y21 inList=%y22 list=%y23 noShade=%y24 option=%y25 updates=%y26 anchor=%y27 cursor=%y28^;
```

| 표시 | 뜻 |
|---|---|
| `v` | 플러그인 버전. 0이면 플러그인이 호출되지 않은 것 |
| `mine` | 플러그인이 칠하려는 헥스 수 |
| `inList` | 그중 게임 그림자 목록에 실제로 들어 있는 수 |
| `list` | 게임 그림자 목록 전체 크기 |
| `noShade` | 게임이 그림자 그리기를 막고 있으면 1 |
| `option` | 게임 옵션 "커서 그림자"가 켜져 있으면 1 |
| `updates` | 이번 전투에서 게임이 그림자 목록을 다시 만든 횟수 |
| `anchor`, `cursor` | 그림자가 속한 헥스와 지금 커서 헥스 |

## 헥스 번호

전장은 가로 17칸, 세로 11줄입니다. `헥스 번호 = 줄 × 17 + 칸`이고, 맨 위 줄 맨 왼쪽이 0입니다.

- 0칸(맨 왼쪽)과 16칸(맨 오른쪽)은 영웅이 서 있는 가장자리라서 두 함수 모두 칠하지 않습니다.
- 그래서 값을 생략해서 0이 들어가도 그림자가 생기지 않습니다.
- 범위가 전장 밖이나 가장자리로 넘어가면 그 부분만 빠집니다.

## 자동으로 지워지는 때

| 때 | 동작 |
|---|---|
| MM0 트리거(마우스 힌트)가 다시 시작될 때 | 이전 그림자와 테두리를 모두 지움 |
| 커서가 MM0 없이 다른 칸으로 갈 때 (예: 주문 대상 고르는 중) | 지움 |
| 전투 행동 시작, 전투 시작/끝, 게임 종료/불러오기 | 지움 |

그래서 MM0 안에서는 지금 보여줄 모양만 호출하면 됩니다. 같은 MM0 안에서 여러 번 호출하면 모양이 합쳐집니다.
MM0 밖(예: `BR`, `BG1`)에서 호출해도 바로 표시되고, 커서가 다른 칸으로 가거나 다음 MM0가 올 때까지 남습니다.

## 예제

`battle_shadows_example.erm`을 모드의 `Data\s` 폴더에 넣고 새 게임을 시작해 전투에 들어갑니다.

```erm
ZVSE2

!?MM0;
!!MM:D?(hex:y);
!!FU(BattleShadow_Radius):P(hex)/1/1;
```

## 알려진 제한

- 옛 WoG 문서 기준으로 MM0는 주문 대상을 고르는 동안에는 발생하지 않습니다. 그동안에는 새 그림자를 만들 수
  없습니다.
- 그림자 색은 게임 기본 그림자(`CCellShd.pcx`) 하나입니다.

## 개발자용 메모

- 게임이 커서 그림자를 그릴 때 쓰는 전역 목록(H3API `H3BattleShadowHexes`)에 헥스를 넣습니다. 그리기와
  HD 32비트 처리는 게임 코드가 그대로 합니다.
- 테두리는 `0x43ED00`(`H3CombatCreature::highlightContour`)으로 켭니다. 게임이 이미 켜 둔 테두리는 건드리지
  않습니다.
- 게임이 그림자 목록을 다시 만드는 `0x493F10`, `0x493A20`, `0x493EF0`에 HiHook을 겁니다. 원본 호출 전에
  플러그인 항목을 빼고, 원본 호출 뒤 커서가 같은 칸이면 다시 넣습니다.
- 반경 계산은 직접 합니다. 어느 줄이 오른쪽으로 밀려 있는지는 실제 헥스 위치(`squares[].left`)에서 읽습니다.
- 목록을 바꾼 뒤에는 `0x4934B0`(BattleMgr::DrawGrid)으로 격자·그림자 층을 다시 만들고, 다시 그리기는 `0x493FC0`을 `aoe_attack.cpp`의 범위 사격 미리보기와 같은 인자로 호출합니다. MM0 안에서는 ERA의
  `OnBattleMouseHint_Quit` 이벤트에서 한 번만 그립니다.
- 주소와 인자는 저장소의 `Combat_SwitchingCreatureAction/aoe_attack.cpp`,
  `ERA_SystemOptionsExtension/CombatSettings.cpp`와 같습니다. 디스어셈블리로 따로 확인하지는 않았습니다.
  마우스를 움직일 때 크래시가 나면 위 세 함수의 인자 수부터 확인하세요.
